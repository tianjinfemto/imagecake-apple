# 与 imagecake 的模块对照

状态标记：✅ 已实现并接线 ｜ 🟡 参数/算子已有、面板入口未接 ｜ ⛔ v1 不做

**总原则**：能力差距不是"漏了"，是**决定不做**。v1 把"端到端能跑通、失败能点名"的部分先做完；
生成式、笔迹坐标系、批量队列这些牵扯面大的模块单独分批。

## 1. 调色与几何

| imagecake 模块 | 本仓状态 | 差异说明 |
|---|---|---|
| 曝光/对比/色温/色调/饱和/色相 | ✅ | 同一套域划分：曝光与白平衡在线性域，其余在显示域 |
| 三区色轮（阴影/中间调/高光） | ✅ | 参数进预设、`ToneEngine` 按亮度权重消费、`ColorGradingPanel` 提供色轮入口；权重和恒为 1，一次只染一片 |
| 八分区 HSL | ✅ | 同上；色相带中心用标准色相角（红0/橙30/黄60/绿120/青180/蓝240/紫285/品红320），与 imagecake 的 CbCr 角序不同、参数序一致。注意环是闭合的：红带与品红带环距仅 40°，同一窗口内会分摊权重（见 `CurveAndToneTests`） |
| 四条曲线（RGB/红/绿/蓝） | ✅ | 单调三次 Hermite（Fritsch–Carlson），屏幕弧线与像素映射同一段插值 |
| 降噪 / 锐化 | ✅ | 双边滤波（保边平滑）+ unsharp mask，作用在调色之后、补丁之前（`SpatialFilters`）；4MP 预览约 0.3–0.8 秒，32MP 导出 3–8 秒 |
| 补光 / 高光柔化 | ✅ | 按亮度三区权重抬暗部 / 压高光（`ToneEngine`，在曲线之前）；只动亮度不染色，形式是 `v+k·(1−v)` 与 `v−k·v`，两端自然饱和不会死白/涂灰。16bit 链的褪色恢复仍未移植 |
| 本地调节（椭圆/笔迹） | ⛔ | 依赖笔迹参考系，与液化同批 |
| 旋转 / 裁剪 / 透视 / 自动水平 | ⛔ | 几何会改画布尺寸并让 α/人脸/笔迹坐标失效，需与"重采集"一起做 |
| 智能构图（auto crop） | ⛔ | 依赖 478 点关键点，本仓只接了 Vision 的框 |

## 2. 人像与 AI

| imagecake 模块 | 本仓状态 | 差异说明 |
|---|---|---|
| 人像分割（MODNet 连续 α） | ✅ | 预处理/后处理口径照实测（sRGB 码、symmetric、长边 512 取 32 倍数、截断取整）；**新增 Vision 兜底** |
| 换底色 / 去色边 | ✅ | 连续 α 合成；defringe 用邻域实心色替换边缘脏色（`EdgeDefringe`，合成前跑，α 不变）；无实心邻居时保守保留 |
| 背景虚化 | ✅ | 三次盒式模糊近似高斯；半径随长边缩放 |
| 智能消除（LaMa） | ✅ | 以选区为中心取 512 正方形窗口；**大选区不做多窗 tiling**（v1 已知降级） |
| 修补工具 / 祛路人 | ⛔ | 同图取样打分那套未移植；LaMa 路线已能覆盖"去掉小物件" |
| 仿制图章 / 液化 / 保护笔刷 | ⛔ | 笔迹参考系与撤销栈是一整块工作 |
| 面部重绘（GFPGAN） | ✅ | 512 定宽、1/255、输出自夹取、椭圆羽化、闭眼不改只点名 |
| AI 超清（ESRGAN x4v3） | ✅ | 互不重叠内部块 + 每块加一圈上下文（不维护浮点权重累加器）；2x 由 4x 降采样 |
| 面部关键点 478 / 五官形变 | ⛔ | 权重在清单里，任务未接线 |
| 美体（RTMPose 17 点） | ⛔ | 权重在清单里，任务未接线 |
| 人脸年龄/性别分组 | ⛔ | 权重在清单里，任务未接线 |
| 老照片褪色/划痕 | ⛔ | 算子未移植 |
| 衣物/证件照换装 | ⛔ | 模板合成与服装分割都不在 v1 |

## 3. 交付与工作流

| imagecake 模块 | 本仓状态 | 差异说明 |
|---|---|---|
| 预设（JSON，v37） | ✅ | 键名逐字对齐；缺键落出厂；未知键点名；比本程序新拒收；外部资产依赖只登记不加载 |
| PNG-8 / JPEG / HEIF | ✅ | ImageIO |
| PNG-16 / TIFF-16 | ✅ | 两个自家容器写入器：PNG-16 用 zlib stored 块；TIFF-16 用 baseline 6.0（小端、单 strip、不压缩、RGBA + 未预乘 alpha）。都用 ImageIO 读回验证，不只看文件头 |
| 色彩空间（ICC / lcms2） | ⛔ | 输入 ICC 由 Core Graphics 在解码时转 sRGB；输出嵌 profile 未做 |
| 水印 / 边框 / 文字贴纸 | ⛔ | 面板与导出链入口都未做 |
| 拼图排版 | ⛔ | 模板名与排版几何未移植 |
| 命名模板 / 尺寸档 | ✅ | 尺寸档（长边上限）+ 文件名模板 `{stem}/{date}/{time}/{index}/{ext}`（`ExportNaming`）；非法字符在生成阶段就清掉，不等写盘时报“路径非法” |
| 批量队列 / CLI | ⛔ | v1 只做单张交互 |
| 联机拍摄 | ⛔ | iPadOS 无 WIA/USB PTP 的等价路径；相机厂商 SDK 不在范围 |
| XMP 导入 | ⛔ | 映射表约 40 键，属独立一批 |
| 用量统计 | ⛔ | 本项目没有点数语义，不需要 |
